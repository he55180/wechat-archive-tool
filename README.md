# 微信公众号一键归档系统

## 项目简介
一键抓取微信公众号文章，自动排版为符合规范的 Word 文档，并同步归档至 Obsidian 知识库。

## 功能特点
- 一键抓取，无需手动复制粘贴
- 自动排版为专业 Word 文档
- 智能关键词分类归档
- 自动生成 Obsidian Markdown 笔记
- Front Matter 自动注入
- 首次启动引导配置，无需手动改代码
- 自动检测并引导安装依赖环境

## 下载安装（推荐）
1. 点击右侧 Releases 下载 `WeChat-Archive-Tool.exe`
2. 双击运行
3. 首次启动按提示选择保存路径
4. 如未安装 Pandoc，程序会自动引导一键安装，全程无需技术基础

## 源码运行（开发者）
1. 安装 Python 3.10+
2. 安装 Pandoc：
   `winget install jgm.pandoc`
3. `pip install -r requirements.txt`
4. `python app.py`

## 自动分类规则
- **1.AI技术汇编**：AI、大模型、Claude 等
- **2.HSE工作笔记库**：安全、吊装、危大 等
- **3.中英文术语库**：术语、翻译、对照 等
- **4.施工技术汇编**：施工、基坑、钢结构 等
- **公众号归档**：未匹配内容兜底存放

## 使用步骤
1. 微信打开公众号文章
2. 右上角复制链接
3. 双击启动程序
4. 点击一键保存
5. 完成！

## 注意事项
- 保持网络连接畅通
- 首次运行需配置保存路径
- Pandoc 程序会自动引导安装
