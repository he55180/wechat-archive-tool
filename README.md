# 微信公众号一键归档系统 (WeChat Archive Tool)

![版本](https://img.shields.io/badge/版本-v1.0.0-green)
![平台](https://img.shields.io/badge/平台-Windows-blue)
![免安装](https://img.shields.io/badge/绿色-免安装-brightgreen)

一键抓取微信公众号文章，自动排版为符合规范的 Word 文档，并同步归档至 Obsidian 知识库。

## 🌟 系统特色与核心优点

### 1. 🍀 零门槛，绿色免安装 (One-File Portable)
* **双击即用**：下载即可运行，无需复杂的 Python 运行环境安装及依赖配置。
* **便携轻量**：程序自动打包了全部运行库。配置路径自动外置于 `config.json`，方便随身携带或通过 U 盘、网盘分发。

### 2. 🏛️ 专业级，公文规范排版 (Layout Formatting)
* **符合 GB/T 9704-2012 国家公文格式标准**：自动将微信文章标题排版为居中 2 号方正小标宋；正文排版为 3 号仿宋体；行间距设定为 28-30 磅；首行缩进 2 字符；页边距严格对齐（天头 37mm、地脚 35mm、左 28mm、右 26mm）。
* **黄金模板嵌套**：转换时自动挂载精美的 Word 黄金模板，生成的 Word 文档无需二次排版，可直接呈报上级单位。

### 3. 📂 智能分类，双重归档同步 (Dual Archive & Auto-Classification)
* **多格式双归档**：在生成 `.docx` Word 文档的同时，可在您的 Obsidian 库中同步生成 `.md` 笔记。
* **关键词自动匹配分类**：系统根据文章标题及正文前 200 字，自动匹配关键词并分类归档至对应目录下：
  * **1.AI技术汇编**：匹配大模型、Claude、Python、API 等。
  * **2.HSE工作笔记库**：匹配安全、隐患、整改、吊装等，并智能追加“HSE”与“吊装”专属标签。
  * **3.中英文术语库**：匹配翻译、中英对照、词汇表等。
  * **4.施工技术汇编**：匹配基坑、钢结构、工程管理等。
  * 对于未匹配内容，自动放入 `公众号归档` 目录进行兜底存放。

### 4. 🎛️ 智能检测，双重环境兜底 (Smart Pandoc Wizard)
* 系统启动时自动检测 `Pandoc` 环境。如未检测到，将开启双重引导：
  * **优先 Winget 自动安装**：一键唤起 PowerShell 自动下载安装并动态刷新系统环境变量。
  * **浏览器跳转兜底**：如因网络限制自动失败，会引导打开官方 Releases 并弹出 2 分钟傻瓜式图文安装指南，确保完全无技术基础的用户也能顺利使用。

## 🚀 快速开始

专为建筑、港口、HSE、工程管理等行业从业人员设计，帮助快速建立个人专业知识库。

### 下载运行（推荐）
1. 点击右侧 Releases 下载 [WeChat-Archive-Tool.exe](https://github.com/he55180/wechat-archive-tool/releases/tag/v1.0.0)
2. 双击运行
3. 首次启动按提示选择保存路径
4. 如未安装 Pandoc，程序会自动引导一键安装，全程无需技术基础

### 源码运行（开发者）
1. 安装 Python 3.10+
2. 安装 Pandoc：`winget install jgm.pandoc`
3. 安装依赖：`pip install -r requirements.txt`
4. 运行程序：`python app.py`

## 📝 自动分类规则
* **1.AI技术汇编**：AI、大模型、Claude、Gemini、GPT 等
* **2.HSE工作笔记库**：安全、吊装、危大、风险、事故、监理等
* **3.中英文术语库**：术语、翻译、对照、词表等
* **4.施工技术汇编**：施工、基坑、钢结构、港口、码头等
* **公众号归档**：未匹配内容兜底存放

## 🛠️ 使用步骤
1. 微信打开公众号文章
2. 右上角复制链接
3. 运行微信一键归档工具
4. 点击一键保存即可完成双格式归档

## ⚠️ 注意事项
* 保持网络连接畅通
* 首次运行需配置保存路径，配置后将保存在 `config.json` 中
* Pandoc 环境会自动检测并引导安装

## 💬 常见问题 FAQ

**Q：抓取失败怎么办？**  
**A**：请检查您的网络连接是否畅通。另外，输入的链接必须是以 `mp.weixin.qq.com` 开头的微信公众号文章完整链接。

**Q：图片不显示怎么办？**  
**A**：请在打开 Word 或 Obsidian 笔记时保持网络连接，程序在转换时已自动处理防盗链机制，使图片可以直接在线拉取并正常显示。

**Q：可以在 Mac 上用吗？**  
**A**：目前发布的免安装绿色单文件版 `.exe` 暂不支持 Mac，仅限 Windows 系统使用。

**Q：Word 排版样式是什么标准？**  
**A**：Word 文档的排版风格及参数设计完全符合 GB/T 9704-2012 国家公文格式标准，让您的报告和笔记具有极高的专业度。
